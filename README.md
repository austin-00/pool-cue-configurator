# 3D Pool Cue Configurator Mockup

An interactive, real-time 3D e-commerce configurator for custom pool cues.

## Features
- **Three.js 3D Viewer:** Fully rotatable 3D model of a pool cue.
- **Real-time Updates:** Changing colors, wraps, and tips updates the 3D materials instantly.
- **Responsive UI:** Designed to work smoothly on both desktop and mobile devices.
- **Simulated Checkout:** UI ready for payment gateway integration.

## Quick Start
Simply open `index.html` in any modern web browser. No build step or local server is required.
